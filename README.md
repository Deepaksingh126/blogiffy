# 📝 Blogiffy

A simple blog app where you can add blogs or write whatever you want.

## 🌐 Live Deployment

Visit the live app here: [https://blogiffy.onrender.com](https://blogiffy.onrender.com)

## 🚀 How to Run the Project Locally

Follow the steps below to run this project on your local machine:

### 1. Clone the Repository

```bash
git clone https://github.com/Deepaksingh126/blogiffy.git
cd blogiffy

```
### 2. create a .env file
and write
```
PORT=8000
MONGO_URI=your_mongodb_connection_string
```
### 3. run the project
```
npm i
```
```
npm run dev
```
or,
```
node app.js
```
